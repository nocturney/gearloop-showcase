# GearLoop — Public Interactive Showcase
A standalone, entirely synthetic and client-side demonstration of concepts and features from the private GearLoop rental/production operations project. It contains no private repository source, tokens, real customers, payment connections, production endpoints or server-side business data.

## Important
This is a **product showcase, not a deployed copy of the production backend**. All actions run locally in the browser and persist only to localStorage. No data is submitted anywhere. Demo data is fictitious. Some represented flows are still under development/review in the private repository and are not release claims.

## Local run
Open index.html directly or serve the folder with `python3 -m http.server 8099 --bind 127.0.0.1`.

## Published version
GitHub Pages serves only these self-contained static files. The source GearLoop repository remains private and untouched.

## Safe usage
Use reset button to restore the initial demo scenario. Never enter real customer information into public demo browsers.
